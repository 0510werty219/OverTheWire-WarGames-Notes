# OverTheWire Wargames 学习笔记集合

> **仓库简介**
>
> 本仓库记录了作者在 OverTheWire Wargames 平台中的闯关学习过程。
>
> 每个 Wargame 均包含从 Level 0 开始的完整 WriteUp 及关键命令记录，旨在沉淀 Linux 基础、Web 安全与二进制利用等领域的实战思路，形成可复现、可复盘的闯关路径。

>**Wargames**
>
>The wargames offered by the OverTheWire community can help you to learn and practice security concepts in the form of fun-filled games.

## 仓库目录结构

本仓库严格按照 Wargame 系列进行目录划分，每个文件夹内包含该系列的完整笔记文档与相关截图。预计最终目录结构如下：

```text
.
├── Bandit/            # Bandit：Linux 基础（33 关）
├── Natas/             # Natas：Web 安全（34 关）
├── Leviathan/         # Leviathan：逆向入门（8 关）
├── Krypton/           # Krypton：密码学（7 关，兴趣选修）
├── Narnia/            # Narnia：二进制利用入门
├── Behemoth/          # Behemoth：二进制利用
├── Utumno/            # Utumno：二进制利用
├── Maze/              # Maze：二进制利用
└── README.md
```

## 笔记说明

每个子目录中包含且仅包含一份 ```WriteUP.md```，以及存放于 images 文件夹中的相关截图。

该文档（```WriteUP.md```）按关卡顺序记录作者的解题思路、关键命令与输出、卡关点与解决方案。

为了便于学习和复盘，笔记中会标注：

- TIP：闯关过程中遇到的问题与注意事项
- NOTE：关键思考、知识点理解或扩展分析

连接方式：所有 shell 类游戏通过 SSH 进行，每关密码即下一关门票。
